# Financial AI Intelligence System

Enterprise-grade AI-powered fraud detection and financial intelligence platform using FastAPI, Kafka, PySpark, ML models, real-time analytics, anomaly detection, risk scoring, and cloud-native microservices.

## Features

- Fraud Detection
- Anomaly Detection
- Real-Time Streaming
- Kafka Integration
- PySpark Analytics
- Risk Scoring
- Distributed Analytics
- Prometheus Monitoring
- Kubernetes Deployment
- CI/CD Pipelines

## Run Application

```bash
docker-compose up --build
```

## API Endpoint

```bash
POST /predict
```
